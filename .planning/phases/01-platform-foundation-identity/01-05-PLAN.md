<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → Nest pipeline | Untrusted bodies, query values, params, headers, and cookies cross into application code. |
| API → PostgreSQL | Runtime configuration and health probes cross into the durable datastore. |
| API process → log sink | Request context can accidentally contain credentials or personal data. |
| host → container | Container privileges, environment values, and image contents affect the runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | global validation | mitigate | Transform/whitelist/forbid-unknown validation applies globally before controller execution; tests cover body/query/param. |
| T-05-02 | Information Disclosure | exception responses | mitigate | Global sanitized error filter and generic 5xx response; internal detail only in structured server logs. |
| T-05-03 | Information Disclosure | Pino request logs | mitigate | Explicit redaction/omission for auth headers, cookies, bodies, secrets, and profiles; log-shape test. |
| T-05-04 | Information Disclosure | health responses | mitigate | Public health returns only status/dependency outcome, never host, version, URL, SQL, or stack. |
| T-05-05 | Elevation of Privilege | container runtime | mitigate | Non-root production image where supported, read-only-safe defaults, explicit secrets, and no host socket/privileged mode. |
| T-05-06 | Denial of Service | readiness dependency probe | mitigate | Bounded database query and non-2xx failure; no unbounded retries or sleep loops. |
| T-05-07 | Tampering | database startup ordering | mitigate | Health-gated Compose dependency, migration-before-serving through the shared `db:deploy` entrypoint, and never parallel migration/runtime startup. |
| T-05-08 | Denial of Service | readiness verification race | mitigate | `docker compose up -d --wait` plus a bounded poll on the real readiness endpoint; no fixed-delay assumption and no unbounded retry. |
</threat_model>
