## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated caller → capability guard | Request context supplies identity but client input may attempt to claim a role. |
| authenticated caller → private database row | A resource identifier can reference another user's retained record. |
| Clerk dashboard → signed token claims | Provider configuration determines which identity facts the API trusts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Elevation of Privilege | capability guard | mitigate | Required capability is server metadata checked against local state; client role fields are not accepted. |
| T-07-02 | Elevation of Privilege | object ownership | mitigate | Owner ID and resource ID are combined in the database predicate; foreign resource returns non-disclosing 404. |
| T-07-03 | Spoofing | Clerk signup/session contract | mitigate | Exact required claim/verification/session instructions plus backend token verification; no webhook or custom credential path. |
| T-07-04 | Information Disclosure | current profile/OpenAPI | mitigate | Typed minimal response excludes Clerk subject/tombstone/audit internals; OpenAPI contains no secrets. |
| T-07-05 | Tampering | unknown DTO fields | mitigate | Global Plan 05 validation rejects client identity/role fields before controller execution. |
| T-07-06 | Repudiation | role/ownership tests | mitigate | Real-database fixtures record observable 401/403/404 outcomes for the customer/admin/other-owner matrix. |
</threat_model>
