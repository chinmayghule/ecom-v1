<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository/PR → GitHub Actions | Untrusted changes and workflow configuration execute in CI with repository privileges. |
| CI script → PostgreSQL service | Tests and migrations receive service credentials and mutate an isolated database. |
| developer machine → clean-snapshot proof | Temporary export/build execution must not inherit hidden local state or alter the canonical working tree. |
| logs/verification document → reviewers | Command output can leak credentials or falsely report a check as passed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Elevation of Privilege | GitHub Actions permissions | mitigate | Least-privilege `contents: read`, no deployment credentials, and no untrusted privileged event in Phase 1. |
| T-09-02 | Tampering | action/dependency versions | mitigate | Reviewed immutable action references, exact manifest pins, frozen lockfile, and dependency audit gate. |
| T-09-03 | Information Disclosure | CI logs | mitigate | Ephemeral service credentials, secret redaction, no real Clerk credentials in normal CI, and sanitized command output. |
| T-09-04 | Tampering | migration/test database | mitigate | Empty isolated PostgreSQL service/database, committed migration deploy, deterministic fixtures, and cleanup. |
| T-09-05 | Repudiation | phase verification | mitigate | Verification document records actual command/timestamp/result; failures and manual blockers remain visible. |
| T-09-06 | Denial of Service | CI/Compose loops | mitigate | Bounded health polling with timeout and no sleep-based readiness or infinite retry. |
</threat_model>
